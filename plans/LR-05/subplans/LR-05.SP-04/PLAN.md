# LR-05.SP-04

## Objective

Assess whether any evidence-supported loop patterns fit the repository's
plan-management and related skills, and identify a proportionate next step.

## Scope

Use the reconciled outputs of S1–S3 and inspect the relevant local skill
guidance, including `plan-management`, `research`, `brainstorm`,
`agent-delegation`, `skill-authoring`, and `context-architecture`. Trace how
those skills currently define exploration, planning, research, review,
execution, and learning from prior work. Map possible loop placements to
concrete steps or handoffs; do not assume that an iterative mechanism would
improve quality simply because the evidence shows it can improve a metric.

For each candidate, state the local need, proposed feedback signal and action,
expected benefit, evidence supporting transfer, measurement independent of the
loop's own proxy, costs, failure risks, and safeguards. Compare a small number
of materially different options, including keeping the workflow as it is.
Recommend a bounded follow-up only if the evidence warrants it. Do not edit
skills, run workflow experiments, or change active processes.

## Output

Record a reviewed fit assessment in this plan's Outcome section: a concise
mapping from evidence-supported patterns to local workflow points, tradeoffs,
uncertainties, and a recommendation or a finding that evidence is insufficient.
Use the prior research audits and local skill text as inputs; no new external
research is assigned.

## Sequence

1. **S1 — Map evidence to local workflow**
   - **Action:** Compare the three reconciled research audits with the named
     skills and identify candidate loop placements and counterarguments.
   - **Output:** A source-linked fit assessment in the Outcome section.
   - **Exit check:** Every candidate is tied to external evidence and a
     specific local workflow point; alternatives, transfer assumptions, costs,
     and risks are considered; independent review is reconciled and the user
     checkpoint is approved.

## Completion criteria

- The assessment uses the current canonical skill guidance and identifies
  concrete workflow points rather than proposing loops in the abstract.
- Transfer from external findings to this repository is labeled as inference
  and supported by explicit applicability assumptions.
- Options show tradeoffs and include the status quo; the recommendation is
  calibrated to evidence quality and practical cost.
- No skill or workflow is changed, and no experiment is run.
- The assessment passes independent review and the user checkpoint.
