# Working search log

## Brief and approach

Question: Where are the loop mechanisms identified in S1 applied in AI
information work, and what evidence exists about intended and observed
outcomes? Intended consumer is the LR-05 coordinator, for reconciliation and
later synthesis. S1 map was an open guide. I collected examples across
generation/refinement, retrieval, feedback learning, coding/checking,
annotation, adaptive experimentation, recommendation, monitoring/governance,
and science. Standard-rigor collection-first discovery; dates below are
2026-09-30. Search results were treated as leads, then direct papers or
accountable guidance opened before inclusion.

## Queries and paths

### Q1 — Generation refinement outcomes and contrary findings

- **Surface/date:** web search and direct proceedings/arXiv pages, 2026-09-30.
- **Exact queries:**
  - `site:aclanthology.org iterative refinement large language model benchmark self-refinement outcomes human evaluation`
  - `large language model self refinement reward hacking iterative feedback negative results study`
- **Purpose:** Locate primary positive evaluations and disconfirmation for self-feedback/output refinement.
- **Candidates inspected:** Madaan et al., *Self-Refine*, arXiv:2303.17651 and NeurIPS PDF; Pan et al., *Spontaneous Reward Hacking in Iterative Self-Refinement*, arXiv:2407.04549; *Feedback Loops With Language Models Drive In-Context Reward Hacking*, arXiv:2402.06627.
- **Decision:** Retained Self-Refine for controlled benchmark/human comparison; Pan abstract for evaluator-versus-human divergence; broader feedback-loop work for simulated test-time harm examples. Used primary pages/PDF rather than index excerpts. Broader paper's constructed Twitter/agent scenarios are not described as observed production events.
- **Marginal finding:** Positive results and contrary outcomes coexist. No single study covers all loop settings; critique fidelity and model capability matter. Self-Refine PDF reveals no gain on initially valid programs and failures due largely to feedback errors.

### Q2 — Executable feedback and code correction

- **Surface/date:** web search; arXiv HTML and ICLR proceedings abstract opened, 2026-09-30.
- **Exact query:** `Teaching Large Language Models to Self-Debug execution feedback results text-to-SQL code translation evaluation`
- **Purpose:** Find code generation where compiler/tests/runtime output is a concrete feedback source and the evaluation compares outcomes.
- **Candidates inspected:** Chen et al., *Teaching Large Language Models to Self-Debug*, arXiv:2304.05128 / ICLR 2024; papers listed in search results on SQL self-play and code self-debugging.
- **Decision:** Retained Chen et al. after inspecting full arXiv HTML for method, task, baselines, and outcomes. Set aside adjacent results for this pass to avoid duplicating related code benchmark evidence without adding a materially different setting.
- **Marginal finding:** Execution results and code explanations feed subsequent attempts. Gains are task-dependent; one Spider debugging step provided only about 0.1% incremental gain in one analysis although total gains versus baseline were larger.

### Q3 — Conversational retrieval/RAG feedback

- **Surface/date:** web search; AAAI article page and paper PDF opened, 2026-09-30.
- **Exact query:** `retrieval augmented generation feedback loop query reformulation user feedback evaluation study retrieval feedback LLM`
- **Purpose:** Find systems that feed retrieval or answer outcomes back into a query/retrieval component, with measured comparison.
- **Candidates inspected:** Wang et al., MaFeRw, AAAI 2025 paper/AAAI page; search leads included retrieval-feedback proposals with no opened full study in this pass, a future-dated “Feedback Adaptation for RAG” listing, and multimodal retrieval results with unclear evaluation role.
- **Decision:** Retained MaFeRw because primary full PDF described the loop, two datasets and comparison metrics, plus transfer analysis and a weak single-reward RL baseline. Excluded future-dated or abstract-only leads and did not count static RAG or query rewrite alone as feedback loops.
- **Marginal finding:** Multi-aspect rewards from gold documents, retrieval ranking and generated response drive a PPO query rewriter. Reported gains are benchmark-based; the primary paper reports an unstable/lower-performing single-reward comparator and remaining complex-intent/re-ranking limitations.

### Q4 — Human preference learning / RLHF

- **Surface/date:** web search; arXiv full HTML and author overview page inspected, 2026-09-30.
- **Exact query:** `RLHF instruction following human feedback randomized comparison InstructGPT results evaluation paper`
- **Purpose:** Verify application from human rating/comparison to model policy update and evidence of intended outcome.
- **Candidates inspected:** Ouyang et al., arXiv:2203.02155; OpenAI InstructGPT overview page.
- **Decision:** Retained the original paper as primary evidence. Used the publisher overview only to navigate, not as separate corroboration. Kept study results distinct from promotional/general alignment language.
- **Marginal finding:** Human preference training improved ratings on the authors' API prompt distribution and some truthfulness/toxicity measures; the model still makes mistakes and transfer is bounded. No independent replication was collected in this S2 sample.

### Q5 — Human annotation / active learning

- **Surface/date:** web search; NIST record and complete NIST TN 2287 PDF opened, 2026-09-30.
- **Exact query:** `"Human-in-the-loop Technical Document Annotation" results 60 users NIST 2287`
- **Purpose:** Find an organizational information workflow where labels update a model and change subsequent human/system work, plus user-study results.
- **Candidates inspected:** Fung et al., NIST TN 2287; NIST catalog abstract; separate NIST PDF.
- **Decision:** Retained original report and inspected active-learning mechanism, crowdsourced study and discussion. Did not treat the catalog abstract as an independent source. The project has two linked studies within one report and NIST producer; not counted as independent corroboration.
- **Marginal finding:** Active learning can redirect document selection and suggest labels, with CTM+AL quality gains in a general-population study. Efficiency/quality tradeoff and codebook absence materially limit interpretation.

### Q6 — Adaptive experiments / bandit allocation

- **Surface/date:** web search; AAAI paper record and PMC full text opened, 2026-09-30.
- **Exact query:** `adaptive bandit experiments mental health engagement 1100 users contextual Thompson sampling results uniform random AAAI 2024`
- **Purpose:** Check the adaptive-experiment subtype identified in S1 against a real deployment and explicit comparator/tradeoffs.
- **Candidates inspected:** Kumar et al., AAAI 2024, article plus PMC full text.
- **Decision:** Retained single study but classified its evidence carefully: actual intervention deployment of 1,100 users, simulations of algorithm reward/FPR/power, and arm response-rate analysis are different result types. Did not present simulation comparison as field effect.
- **Marginal finding:** The article reports higher simulated reward in a context-dependent scenario but lower power at small N and elevated FPR at large N under no difference; field response rates for the tested Link arm show no large difference and engagement ratings are sparse.

### Q7 — Recommender exposure-response-retraining feedback

- **Surface/date:** web search; arXiv primary paper opened, 2026-09-30.
- **Exact query:** `Krauth Wang Jordan Breaking Feedback Loops in Recommender Systems with Causal Inference paper simulation results`
- **Purpose:** Capture the existing S1 recommender mechanism and see what evidence exists beyond a conceptual taxonomy.
- **Candidates inspected:** Krauth et al., arXiv:2207.01616; arXiv abstract and sections defining the dynamic causal process/CAFL.
- **Decision:** Retained as primary method/simulation evidence, expressly marked simulated and not field deployment.
- **Marginal finding:** Recommendations influence user responses and later training data; CAFL is reported to improve recommendation quality over prior corrections in simulation. This is an application pattern plus methodological evidence, not measured user welfare or production impact.

### Q8 — Monitoring/governance and actual deployment outcomes

- **Surface/date:** web search; NIST official pages/report, institutional clinical monitoring report and PLOS article opened, 2026-09-30.
- **Exact queries:**
  - `AI monitoring deployed system feedback loop measured outcomes operational study model monitoring feedback`
  - `post deployment model monitoring AI governance framework NIST deployed monitoring actions evidence official`
- **Purpose:** Separate formal governance/monitoring capability from measured post-deployment effects and locate null/negative operational evidence.
- **Candidates inspected:** Keyes et al., *Monitoring Deployed AI Systems in Health Care*, PMC full text identified on inspection as a Jan. 2026 arXiv preprint (not peer reviewed); Kopanitsa, PLOS Digital Health 2026 longitudinal retrospective study; NIST AI RMF Core; NIST AI 800-4 report and NIST news page; Vanderbilt monitoring system search result.
- **Decision:** Retained Stanford as documented workflow (plans, owners, actions) but corrected its apparent journal-search result: the opened full-text page explicitly labels it an arXiv preprint, so it is not peer-reviewed. Retained PLOS as empirical drift/telemetry study, and NIST as normative/landscape sources. Did not use the NIST news story separately from its full report. Did not include Vanderbilt in the final evidence because direct article retrieval returned an internal error; no inference was drawn from the search result alone.
- **Marginal finding:** Clinical systems can degrade after validation; operational indicators may precede slow outcome labels. Yet the PLOS study does not test whether a remediation loop changes outcomes. Governance sources explicitly document monitoring and action but are not effectiveness trials.

### Q9 — Scientific experiment selection

- **Surface/date:** web search and arXiv primary abstract, 2026-09-30.
- **Exact query:** `site:arxiv.org active learning closed-loop autonomous materials discovery Bayesian active learning outcome experiment CAMEO`
- **Purpose:** Check S1's scientific discovery probe for specific mechanism and reported outcome.
- **Candidates inspected:** Kusne et al., CAMEO materials discovery, arXiv:2006.06141, *Nature Communications* 2020.
- **Decision:** Retained as an explicit but bounded example. Abstract reports a closed active-learning lab cycle and novel phase-change material. Did not use as comparative efficacy evidence; full paper not inspected in S2.
- **Marginal finding:** Cycles take seconds to minutes in the described beamline system, but the abstract alone does not supply a non-loop comparator.

## Terms added, rejected, and marginal scope decisions

- Terms followed from S1: `self-refinement`, `reward hacking`, `self-debugging`, `human feedback`, `RLHF`, `query rewriting`, `retrieval feedback`, `active learning`, `contextual Thompson sampling`, `feedback loops recommender`, `post-deployment monitoring`, `responsible AI lifecycle`, `closed-loop materials discovery`.
- Kept “AI information work” tied to a recurring information/action or feedback path; not every sector using AI was counted as a loop.
- Separated monitoring plans and governance frameworks from demonstrated effectiveness. Separated adaptive-bandit simulations from actual intervention outcomes. Separated benchmark improvements from field outcomes.
- Did not pursue generic AIOps or other domain inventories absent a specific source supporting a repeated cycle and outcome. Did not include vendor statements as effectiveness evidence.
- The NIST AI 800-4 and PLOS 2026 articles are within the current date boundary (published March and July 2026 respectively).

## Stop rationale and handoff notes

The searches yielded primary cases for each materially different mechanism raised by the brief, including positive, negative, mixed and largely documentary evidence. Primary full texts were inspected for the cases where benchmark/evaluation detail materially informs claims; abstract-only detail is marked for Pan et al. and CAMEO. The source mix and coverage limit are made explicit in the audit. Further discovery could add many domain examples but is less likely to alter this map. Important gaps remain: independent replications, field testing of monitoring-to-remediation loops, and real-user effects in RAG/recommender cases. The S2 audit stops without making workflow recommendations or beginning S3.
