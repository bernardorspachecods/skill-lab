# Patterns

Patterns are teaching instruments. They show reusable structures of thought without forcing every task into a form.

Use them when a task is ambiguous, high-risk, repeated, or likely to create stale memory.

Do not use them when a direct answer or small verified change is enough.

## Available Patterns

- `task-router.md`: classify a human request before acting.
- `context-map.md`: choose relevant context and exclude noise.
- `memory-update.md`: decide what to keep, update, archive, or discard.
- `verification-plan.md`: match verification strength to task risk.
- `research-source-note.md`: turn a source into durable research knowledge.
- `app-workflow-audit.md`: inspect an app's existing LLM/workflow docs without copying this repo blindly.
