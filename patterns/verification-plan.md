# Verification Plan Pattern

Use this before claiming work is complete.

## Goal

Match the verification method to the risk of the task.

## Pattern

```markdown
# Verification Plan

Claim or change to verify:

Risk level:

Weakest acceptable check:

Strongest practical check:

Evidence produced:

What this does not prove:

Remaining risk:
```

## Good Behavior

- The model names what was checked.
- The model names what the check does not prove.
- The model reports failed or unavailable verification honestly.

## Bad Behavior

- Saying "verified" without evidence.
- Treating self-review as enough when tests or sources exist.
- Letting a narrow check support a broad claim.
