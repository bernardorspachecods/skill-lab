# Research Source Note Pattern

Use this when converting an article, PDF, doc page, or source corpus into durable knowledge.

## Goal

Prevent premature synthesis and keep source traceability.

## Pattern

```markdown
# Source Note

Source ID:

Title:

Author / organization:

URL or path:

Publication date:

Date inspected:

Authority level:

Scope:

Limitations:

Relevant sections or locators:

Useful claims:

Warnings:

Examples worth reusing:

What this changes:

Open questions:
```

## Good Behavior

- The model records what the source is authoritative for.
- The model extracts practical claims and warnings.
- The model keeps locators for later verification.

## Bad Behavior

- Summarizing everything.
- Copying source wording into final docs without synthesis.
- Using the source outside its scope.
