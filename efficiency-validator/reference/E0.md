# E0 — Efficiency validator foundation

## Objective

Establish the original phased plan for a reusable validator that records
observable LLM-run costs, adjudicates answer quality, compares equivalent runs,
and supports an explainable efficiency verdict.

## Scope

The plan covered provenance and token/filesystem observability, reusable run
capture, quality gates, paired comparison, and validation of the resulting
tooling. It is preserved as implementation history; the later V0/P0 plans
supersede it for current work.

## Output

The completed E1–E5 plan tree and its implementation history, retained in this
directory for traceability.

## Plan tree

- [E1 — Token and filesystem observability](E1-observability.md)
- [E2 — Reusable capture and artifacts](E2-validator.md)
- [E3 — Quality gate and answer adjudication](E3-quality-gate.md)
- [E4 — Paired comparison and automatic verdict](E4-comparison.md)
- [E5 — Validation and operationalization](E5-validation.md)

## Sequence

1. **E1 — Establish observability**
   - **Output:** Token and filesystem evidence contracts with explicit
     unavailable states.
   - **Exit check:** [E1](E1-observability.md) is complete.
2. **E2 — Build reusable capture**
   - **Output:** Controlled run bundles, manifests, and stable capture
     interfaces.
   - **Exit check:** [E2](E2-validator.md) is complete.
3. **E3 — Add the quality gate**
   - **Output:** Deterministic quality adjudication with prohibited-claim and
     support checks.
   - **Exit check:** [E3](E3-quality-gate.md) is complete.
4. **E4 — Compare equivalent runs**
   - **Output:** Normalized costs, deltas, trade-offs, and automatic verdicts.
   - **Exit check:** [E4](E4-comparison.md) is complete.
5. **E5 — Validate and operationalize**
   - **Output:** Fixtures, regression coverage, and documented remaining
     blind spots.
   - **Exit check:** [E5](E5-validation.md) is complete.

## Completion criteria

- E1 through E5 are complete and retained as historical implementation
  records.
- The validator can expose evidence limits instead of silently treating missing
  signals as zero cost.
- Later hardening plans explicitly supersede this original foundation.
