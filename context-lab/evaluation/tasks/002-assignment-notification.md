# Case 002 — Assignment notification

A product change requires creating a task assigned to another workspace member
and notifying that person asynchronously. Trace the current behaviour across
product rules, the core use case, persistence, the HTTP adapter, and the
worker. Identify the source of truth for the membership check and the point
where delivery becomes asynchronous. Identify any missing or differently
shaped behaviour. Report the files and any missing behaviour. Do not edit the
repository.
