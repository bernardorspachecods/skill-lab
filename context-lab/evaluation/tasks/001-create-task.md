# Case 001 — Create a task

Review the existing baseline behaviour that lets a user create a task in a
project. Identify the authoritative product rule, the application path that
enforces it, the persistence seams that are actually available, and the tests
that protect the behaviour. Determine whether the requested behaviour already
exists and separate any in-memory demo path from a durable adapter. Report the
files and explain the evidence path. Do not edit the repository.
