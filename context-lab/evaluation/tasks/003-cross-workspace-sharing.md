# Case 003 — Cross-workspace sharing

A stakeholder proposes allowing one project to belong to two workspaces.
Assess whether the canonical repository currently supports that proposal.
Find the governing product rule, the architectural decision behind it, the
implementation assumptions, and the likely change surface. Distinguish current
behaviour from a recommended future design. Accept that multiple coherent
future designs may exist; identify the affected permission and persistence
concerns rather than inventing an exact file list. Do not edit the repository.
