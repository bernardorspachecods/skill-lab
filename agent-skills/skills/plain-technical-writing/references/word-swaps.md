# Word swaps

These are review prompts, not mandatory substitutions. Keep the original term when it is a domain term or when the substitution changes meaning.

| Prefer | Review or replace |
| --- | --- |
| use | utilize, leverage, make use of |
| to | in order to |
| before | prior to |
| if | in the event that |
| because | due to the fact that |
| for example | e.g. |
| that is | i.e. |
| can | enables, allows, when the meaning is capability |
| inspect, measure, or verify | ensure, when the intended action is more specific |
| a measurable property | robust, powerful, seamless, comprehensive |
| the specific fact | simply, easily, clearly, obviously |

Delete filler such as “in conclusion” or “in summary” when the surrounding structure already shows the conclusion. Replace “should” only when the intended force is clear: use “must” for a requirement, “can” for capability, or a direct statement for an observation.

Check every proposed swap against the surrounding sentence. Do not weaken a requirement, erase uncertainty, or change a technical distinction for the sake of simpler vocabulary.
