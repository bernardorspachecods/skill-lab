# Synthesis

The current source base supports a practical field manual for LLM behavior in agentic workflows, context engineering, tool use, verification, coding-agent practice, and research memory.

The strongest durable principles are:

- start with the smallest sufficient workflow;
- route the task before loading context;
- treat context as a finite attention budget;
- retrieve details just in time;
- keep source notes separate from synthesis;
- preserve uncertainty instead of smoothing it away;
- use tools to ground the model in external state;
- make humans the final quality gate for high-impact decisions;
- store only memory that changes future behavior;
- verify with sources, tests, tools, or environment checks when available.

The current source base should not be stretched into:

- a complete theory of LLM internals;
- a full human-computer interaction guide;
- security governance for tool-using agents;
- regulated-domain guidance;
- master-thesis methodology.

Those areas need additional primary sources before durable encyclopedia entries are added.
